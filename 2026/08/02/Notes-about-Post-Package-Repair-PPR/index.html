What

PPR(Post Package Repair)是一种 DRAM内部的修复(repair)机制，通过备用 Row(spare row)替换故障 Row，使DRAM继续可靠工作。

简单理解：

PPR = DRAM发现某个row永久失效后，把该row映射到备用row。

分类

Intel Xeon 6 RAS文档中提到：

supports both runtime soft Post Package Repair (sPPR) and power-up hard Post Package Repair (hPPR)

也就是说：

  • sPPR：运行时修复
  • hPPR：启动阶段永久修复

Hard PPR (hPPR), for a permanent row repair, and Soft PPR (sPPR), for a temporary row repair.

PPR和Memory Sparing区别

二者关系：

PPR是Memory Sparing的一种。

区别主要在粒度：

PPR Rank/DIMM Sparing
粒度 Row Rank/DIMM
位置 DRAM内部 Memory Controller/平台
备用资源 Spare Row Spare Rank/DIMM
控制者 DRAM内部repair logic Memory Controller/RAS firmware

PPR vs ADDDC vs Chipkill

它们解决不同问题：

简单理解：

技术 解决的问题
ECC bit错误
Chipkill chip/device故障
ADDDC 预测device故障并增强保护
PPR 替换坏row

总结

Post Package Repair（PPR）是DDR5时代重要的DRAM RAS技术，本质是一种row-level Memory Sparing：当DRAM某个row出现永久故障时，利用备用row建立地址重映射，使坏row被透明替换，从而避免故障升级为系统错误。DDR5进一步支持sPPR（运行时临时修复）和hPPR（永久修复）。
