本文将比较x86和ARM的memory ordering的差异。

x86 与 ARM 的核心差异可以先浓缩成一句话：

x86 保留了绝大多数程序顺序，只放松了少数情况；ARM 默认只保留必要的顺序，其他顺序需要软件通过acquire、release 或 barrier 明确表达。
